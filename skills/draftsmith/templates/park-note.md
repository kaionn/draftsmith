# Park note: {branch} 第 {N} 巡

<!--
delivery run を park するときの散文引き継ぎ。state には入らない local artifact で、
Git metadata 配下に 0600 で置かれる。次の session はこれを SessionStart で受け取る。

書かないもの:
- secret / credential / token / API key
- 顧客を特定できる情報
- PR 本文・review コメント・CI ログの転載（リンクと 1 行要約で足りる）
- 会話履歴の書き起こし

## 第 N 巡

この park が何巡目か、前の巡から何が変わったか。1〜3 行。

## 待っているイベント

何の到着を待って park したか。到着の確認方法（`gh pr view` の
どのフィールド、どの check 名）まで書く。

## 決定と却下案

採用した設計判断と、却下した案とその理由。「なぜ却下したか」が本体で、
次の session が同じ案を再提案するのを止めるために書く。

## 実測した検証（コマンドと結果）

実際に走らせたコマンドと、その出力の要点。通ったものと落ちたものを
両方書く。走らせていないものはここへ書かない。

## 既知の脆さ・未検証項目

分かっているが直していないこと、未検証のまま残した前提、次に触ると
壊れそうな場所。「無い」なら「無い」と書く。
